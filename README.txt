منصة تاريخ الرقي — النسخة المطورة
================================

محتويات المشروع:
- index.html: هيكل الواجهة.
- style.css: التصميم والألوان والحركات والاستجابة للهاتف والتابلت والكمبيوتر.
- script.js: تسجيل الدخول والتسجيل والوضع الليلي/النهاري والمساعدة والقائمة.
- server.js: خادم API للحسابات والجلسات.
- package.json: حزم Node.js المطلوبة.

تشغيل الخادم محليًا:
1) ثبّت Node.js 20 أو أحدث.
2) افتح Terminal / PowerShell داخل مجلد المشروع.
3) ثبّت الحزم:
   npm install
4) أنشئ قيمة سرية طويلة قبل التشغيل.

على Linux/macOS:
   export SESSION_SECRET="اكتب-هنا-قيمة-سرية-عشوائية-طويلة-لا-تشاركها"
   npm start

على Windows PowerShell:
   $env:SESSION_SECRET="اكتب-هنا-قيمة-سرية-عشوائية-طويلة-لا-تشاركها"
   npm start

5) افتح:
   http://localhost:3000

يُنشئ الخادم مجلد data وقاعدة SQLite لحسابات الطلاب والجلسات تلقائيًا.
لا ترفع مجلد data إلى مستودع عام.

مهم قبل النشر:
- استخدم HTTPS على الاستضافة واضبط NODE_ENV=production.
- اضبط SESSION_SECRET قويًا وسريًا في إعدادات الاستضافة، وليس داخل الكود.
- تأكد من سياسة الخصوصية وموافقة ولي الأمر/المدرسة عند الحاجة قبل جمع بيانات الطلاب.
- لا تستخدم هذا المشروع لجمع بيانات حقيقية قبل اختبار الأمان والنشر الصحيح.
- استعادة كلمة المرور والتحقق برسالة SMS غير مفعّلين.
- لا تضع كلمات المرور أو الأسرار داخل ملفات الواجهة.
- قاعدة SQLite مناسبة كبداية صغيرة، وقد تحتاج قاعدة بيانات مُدارة عند التوسع.

إذا فتحت index.html مباشرة من مدير الملفات، ستعمل الواجهة كمعاينة فقط.
لتسجيل الحسابات وحفظها فعليًا، افتح الموقع عبر الخادم على localhost:3000.
